# Risk model artifacts

`coastal_risk_v1.json` is generated by `ml/coastal_risk/train.py`.

The gateway validates its schema, class order, feature order, dimensions and
finite numeric values before use.  It never loads pickle or joblib files.  If
the artifact is absent or invalid, the API stays available and reports the
explicit `rule-fallback` source.

Set `COAST_RISK_MODEL_PATH` only when testing a different trusted JSON artifact.
